# Privacy

Phase 1 stores **no personal data**. This folder will hold the privacy-by-design documentation as features land.

## Design commitments (to be implemented and verified in later phases)

- Data minimisation and purpose limitation: collect only what a feature needs.
- Consent captured where required, with a record of what was agreed.
- User data export and account deletion.
- Privacy preferences and retention policies per data type.
- Sensitive evidence documents stored privately and never exposed through public URLs.
- Audit trail for access to sensitive data.

The legal pages (`/privacy`, `/data-protection`, …) are placeholders; the final text needs review by qualified
counsel. Do not publish compliance claims until they are true and verified.
